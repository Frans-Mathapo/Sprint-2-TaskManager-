# Sprint 2 – Task Manager

## 🛠️ Project Setup

Follow the steps below to clone the project and set up your local development environment.

### 1. Clone the Repository

**NB:** Make sure you are inside your project's directory before running the command.

```bash
git clone "https://github.com/Frans-Mathapo/Sprint-2-TaskManager-.git"
```

Move into the project directory:

```bash
cd Sprint-2-TaskManager-
```

### 2. Configure Git

Set your Git email address:

```bash
git config --global user.email "user@email.com"
```

Set your Git username:

```bash
git config --global user.name "name.surname"
```

> Replace `user@email.com` and `name.surname` with your own Git configuration details.

### 3. Create Your Own Branch

Create and switch to your own branch:

```bash
git checkout -b YourBranchName
```

For example:

```bash
git checkout -b Frans
```

### 4. Create a Python Virtual Environment

Create a virtual environment named `.venv`:

```bash
python -m venv .venv
```

### 5. Activate the Virtual Environment

If you are using **Windows PowerShell**, run:

```powershell
.venv\Scripts\Activate.ps1
```

Once activated, you should see `(.venv)` at the beginning of your terminal prompt.

### 6. Install Pandas

Install the required `pandas` package:

```bash
pip install pandas
```

### Setup Complete

You are now ready to work on the project.

Before making changes, make sure you are working on **your own branch**:

```bash
git branch
```

You can then start developing and committing your changes.
